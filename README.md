# نموذج أضف سؤالك القانوني | Ask Lawyer Form

نموذج ويب احترافي مخصص لتلقي الاستفسارات القانونية من الزوار، مقدم من موقع [محمود شرابي للمحاماة](https://sites.google.com/view/mahmoud-sharaby-lawyer).

## المميزات

- تصميم احترافي ومتجاوب يدعم اللغة العربية (RTL).
- حقول مخصصة لجمع أهم المعلومات مثل الاسم، البريد الإلكتروني، رقم الهاتف، ونص السؤال.
- إرسال آمن وسهل باستخدام [FormSubmit](https://formsubmit.co/).
- عرض رسالة تأكيد بعد الإرسال تلقائيًا.
- يدعم رفع مستندات (اختياري).
- أيقونات جذابة باستخدام مكتبة Lucide.

## الاستخدام

1. افتح الملف `index.html` في المتصفح.
2. أدخل بياناتك بدقة.
3. اضغط على زر "إرسال الاستشارة".
4. ستظهر لك رسالة تأكيد تفيد بنجاح عملية الإرسال.

- فقط اتصال بالإنترنت لتفعيل الإرسال عبر FormSubmit.

## الترخيص

هذا المشروع مجاني ومتاح للاستخدام المفتوح، ويمكن تعديله وتخصيصه حسب الحاجة.
